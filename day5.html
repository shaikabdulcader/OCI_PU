02Networking Basics

What is Networking?

Networking = connecting devices so they can communicate. Think of a city: houses are computers, roads are cables, the traffic police is the router, the security checkpost is the firewall, and every house has an address (IP).

🏠 LAN — Local Area Network

Everything inside ONE building: laptop, desktop, printer, server. Example: a college computer lab where all systems are connected together.

🌍 WAN — Wide Area Network

Connects multiple LANs across cities: College → Internet → Oracle Cloud. The Internet itself is the biggest WAN.

Packet Switching

Data is never sent as one big file. It's split into small packets — like a courier company sending 4 trucks instead of 1 huge one — and reassembled at the destination.

Why split?Small packets can take different roads, survive one road failing, and be re-sent individually if lost. Exactly how the Internet works — every image you load arrives as reassembled packets.

09Gateways

The 5 Gateways — Pick the Right Door

Gateways are the doors of your VCN — each opens to a different place. Learn the memory tricks, then answer the scenarios.

🌐 Internet Gateway

"Everyone can visit me." Two-way door to the public Internet — for public subnets.

🥷 NAT Gateway

"I can go outside, nobody comes inside." Outbound-only Internet for private subnets.

🛗 Service Gateway

"Only OCI services." Private corridor to Object Storage & co. without touching Internet.

🏢 DRG

"Office connection." Dynamic Routing Gateway links your VCN to on-premises networks.

🏘 LPG

"Neighbor VCN." Local Peering Gateway connects another VCN in the same region.

🎯 Scenario Drill — which gateway?

1. A private database server needs to download security patches from the Internet — but must never be reachable FROM the Internet.
✓ NAT Gateway — outbound only. The server goes out for patches; nobody comes in. "I can go outside, nobody comes inside."
2. Your public website must be reachable by customers worldwide.
✓ Internet Gateway — the two-way public door. "Everyone can visit me."
3. A private VM must back up files to OCI Object Storage without any Internet exposure.
✓ Service Gateway — a private corridor straight to OCI services. Traffic never touches the Internet.
4. Your company's on-premises data center must connect securely to the VCN.
✓ DRG — the "office connection" for VPN / FastConnect links to on-premises networks.
5. Two VCNs in the SAME region need to talk privately to each other.
✓ LPG — Local Peering Gateway, the "neighbor VCN" door within one region.

16Storage

Storage Chooser — Warehouse, SSD, or Shared Folder?

Three storage services, three jobs: Object Storage = warehouse for files. Block Storage = personal SSD for one VM. File Storage = office shared folder for many VMs. Pick the right one per scenario.

📦 Object Storage

Warehouse. Images, videos, backups, documents — unlimited files, reached over APIs.

💽 Block Storage

Personal laptop SSD. A disk attached to ONE VM — for the OS, databases, apps.

🗂 File Storage

Office shared folder. Many VMs mount the same files at once (NFS).

🧪 Try each storage yourself

Click an action to see how each storage type behaves.

🎯 Scenario Drill — pick the right storage

1. Store 10 million product photos and nightly backups.
✓ Object Storage — the warehouse. Massive amounts of files, cheap, durable.
2. A database VM needs a fast disk for its data files.
✓ Block Storage — the personal SSD. High-performance disk attached to one VM.
3. Three app servers must all read/write the SAME shared documents.
✓ File Storage — the shared office folder. VM1 + VM2 + VM3 mount it simultaneously.

Cheat Sheets

Networking

  • LAN = one building · WAN = connects LANs
  • Data travels as packets, reassembled at destination
  • Switch = inside a network · Router = between networks

CIDR & Subnets

  • 10.0.0.0/16 = 65,536 IPs · bigger /number = smaller network
  • Public subnet = Internet-reachable · Private = not
  • Never overlap CIDRs; never duplicate IPs

Routing & Gateways

  • Route table = Google Maps · longest prefix wins
  • 0.0.0.0/0 → Internet Gateway = "everywhere else"
  • IGW public · NAT outbound-only · SGW OCI services · DRG on-prem · LPG neighbor VCN
  • Peering: overlapping CIDRs can't peer · SL = subnet guard, NSG = per-VM lock

Compute & Storage

  • Shape = VM specs · Boot Volume = the OS disk (no boot volume, no start)
  • cloud-init = automatic first-boot setup · SSH keys > passwords
  • Metadata = the VM's identity card (OCID, region, AD, shape)
  • Object = warehouse · Block = personal SSD · File = shared folder
  • Terraform creates · Ansible configures
